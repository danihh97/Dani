# AhorraFuel Tycoon — Demo
Demo móvil de gestión de gasolinera.

## Probar
La forma fiable de probarla en iPhone es desplegar esta carpeta en Vercel:
1. Sube `index.html` a un repositorio de GitHub.
2. Importa el repositorio en Vercel.
3. Deploy.
4. Abre la URL desde Safari.

No necesita backend para esta demo. La partida se guarda en localStorage.
